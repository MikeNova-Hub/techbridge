The 30-Day Practical Internship

Eight tasks. One journey.

TechBridge provides a structured 30-day practical internship. You build your web development skills step by step by completing practical projects, and each task is a little more challenging than the one before it. By the end, you will have built a complete TechBridge platform.

See the Roadmap View Programs
30 Days of practical experience
8 Practical tasks to complete
4 Difficulty levels, from Beginner to Advanced Beginner

THE TASK ROADMAP

Start simple. Finish with a full platform.

  1. DAY 1
    TASK 01 Available

    Build the TechBridge Homepage

    Create the first version of the TechBridge website using HTML and CSS.

    Beginner View details

    What you will build

    The first version of the TechBridge homepage. This is the foundation that the later tasks grow from.

    Tools

    • HTML5
    • CSS3
  2. DAY 4
    TASK 02 Available

    Build the TechBridge Programs Experience

    Create a Programs experience that presents TechBridge's available learning programs.

    Beginner → Intermediate View details

    What you will build

    A Programs page or section that presents the learning programs clearly, and that feels like a natural continuation of your Task 1 homepage.

    Tools

    • HTML5
    • CSS3
  3. DAY 8
    TASK 03 Available

    Build the Internship Tasks Experience

    Create an interface that presents the TechBridge internship tasks and helps users understand the internship journey.

    Beginner → Intermediate View details

    What you will build

    An experience that shows all 8 internship tasks, when each one starts, and how the work becomes more challenging over the 30 days.

    Tools

    • HTML5
    • CSS3
  4. DAY 11
    TASK 04 Upcoming

    Build an Interactive Task Tracker

    Use JavaScript to make the internship task experience interactive and allow progress to be tracked.

    Intermediate View details

    What you will build

    An interactive version of the internship task experience, where progress can be tracked.

    Tools

    • JavaScript
  5. DAY 15
    TASK 05 Upcoming

    Build the Intern Registration Experience

    Create a professional registration/onboarding interface for TechBridge interns.

    Intermediate View details

    What you will build

    A professional registration and onboarding interface for new TechBridge interns.

    Key parts

    • Registration
    • Onboarding
  6. DAY 19
    TASK 06 Upcoming

    Build the Task Submission System

    Create an interface through which interns can prepare and submit their task work.

    Intermediate View details

    What you will build

    An interface where interns prepare their work and then submit it.

    Key parts

    • Preparing work
    • Submitting work
  7. DAY 22
    TASK 07 Upcoming

    Build the Intern Dashboard

    Create a dashboard where an intern can view their profile, progress, tasks, and submissions.

    Intermediate → Advanced Beginner View details

    What you will build

    A dashboard that brings an intern's information together in one place.

    Key parts

    • Profile
    • Progress
    • Tasks
    • Submissions
  8. DAY 26
    TASK 08 Upcoming

    Build the Complete TechBridge Internship Platform

    Combine the different components created during the internship into a complete TechBridge platform.

    Intermediate → Advanced Beginner View details

    What you will build

    The finished TechBridge internship platform, made by combining the components you created in the earlier tasks.

    Key parts

    • Bringing everything together
